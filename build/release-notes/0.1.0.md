## Playgrounds 0.1.0

Initial public release of Playgrounds, a lightweight desktop AI playground for
OpenAI-compatible endpoints.

### Highlights

- Incremental response streaming with separate connection profiles and model discovery.
- Per-connection model, temperature, max tokens, and system prompt settings.
- Local conversation history, conversation management, and edit-as-copy workflows.
- Light and dark themes, response statistics, and an English (US) interface.
- API keys stored in Windows Credential Manager, separate from conversation files.
- Update checks and installer downloads through Settings > Updates.

### Install

Download `Playgrounds-0.1.0-x64.msi` for Windows 10/11 x64. Python is not required.
Installation is per-user, with a Start Menu shortcut and no administrator elevation.
Connect your own OpenAI-compatible endpoint; this release does not include an AI model
or API credentials. Provider access and any usage charges are managed separately.

### Security and Limitations

This release is **unsigned**. Windows may show Unknown publisher or a SmartScreen
warning. Do not bypass warnings for files from untrusted sources. Compare the installer
SHA-256 with `SHA256SUMS.txt`; a checksum does not replace a publisher signature.

The supported installer targets Windows x64 only. The application interface is English
(US) only. Endpoint feature support depends on the connected provider.

### Included Assets

- `Playgrounds-0.1.0-x64.msi`: Windows installer.
- `update.json`: stable updater manifest with the installer URL and SHA-256.
- `Playgrounds-0.1.0-source.zip`: project source and build scripts from this release tag.
- `build-environment.json`: source commit and build dependency versions.
- `SHA256SUMS.txt`: checksums for the assets above.
