Material Line Icons by Vjacheslav Trushkin
https://github.com/cyberalien/line-md
https://icon-sets.iconify.design/line-md/

Bundled SVGs are from Iconify's line-md collection (version 3.0.5):
https://github.com/iconify/icon-sets/blob/master/json/line-md.json
Animation elements have been evaluated at their final values and removed for
static, immediately visible QtSvg rendering. Drawing-only stroke dash arrays
and offsets have been removed. Original geometry and currentColor are retained.

Application mappings:
plus -> plus; send -> arrow-up; stop/maximize -> square; sliders -> cog;
trash -> trash; theme -> sunny; copy/restore -> text-box-multiple;
check -> confirm; close -> close; eye -> watch; eye-off -> watch-off;
refresh -> rotate-270; save -> download-outline; minimize -> minus;
chevron-down -> chevron-down; brand -> chat-round-dots.
